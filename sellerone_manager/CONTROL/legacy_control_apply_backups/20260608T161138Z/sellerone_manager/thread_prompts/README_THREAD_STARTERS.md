## Main Rule

Every worker or sub-manager chat must start from the manager evidence and approved packet, not from chat memory.

They must not drift into business actions. Protected actions stay blocked:

- prices
- queues
- Google Sheets writes
- publishing
- local DB alignment
- output deletion
- worker restart
- live worker cycle without approved proof window
- business decisions

## Reply Style

Ask each chat to reply in this shape:

```text
Decision needed: yes/no

Plain-English status:
<what this cycle now proves>

Codex-owned next step:
<what the agent did or will do next>

Stopped or parked:
<only if something crossed a protected boundary>
```
